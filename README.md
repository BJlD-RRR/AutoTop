# AutoTop

Простий landing page для автосалону з каталогом автомобілів і контактами.

## Опис проєкту

Цей проєкт — статична веб-сторінка з інформативним дизайном для продажу автомобілів. У сторінці є:

- головна сторінка з hero-блоком;
- секція з перевагами компанії;
- блок з популярними автомобілями;
- сторінка з каталогом авто;
- сторінка контактів.

## Структура файлів

- `index.html` — головна сторінка
- `cars.html` — каталог автомобілів
- `contact.html` — сторінка контактів
- `style.css` — стилі проєкту
- `images/` — графічні файли
